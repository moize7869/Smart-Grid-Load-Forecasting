# ⚡ Smart Grid Load Forecasting & Anomaly Detection

An AI-powered simulation pipeline designed to forecast electricity demand and detect abnormal load spikes in a smart grid environment. This capstone project was developed for the AI for IoT curriculum at M. H. Saboo Siddik College of Engineering.

## 🚀 Project Overview
Modern smart grids require resilient monitoring to prevent overloads and detect anomalies like power theft or equipment failure. This software-only IoT simulation generates synthetic smart meter and temperature data to model these real-world infrastructure scenarios.

### Core Features
* **Simulated IoT Sensors:** Generates robust time-series telemetry for power load (kW) and ambient temperature.
* **Predictive Modeling:** Utilizes Linear Regression to forecast hourly electricity demand based on historical cycles.
* **Anomaly Detection:** Implements an Isolation Forest algorithm to autonomously flag sudden, abnormal power spikes.
* **Interactive Dashboard:** A live Streamlit web application visualizing actual vs. predicted loads alongside detected anomalies.

## 🛠️ Tech Stack
* **Language:** Python
* **Data Processing:** Pandas, NumPy
* **Machine Learning:** Scikit-Learn (Linear Regression, Isolation Forest)
* **Visualization:** Matplotlib, Streamlit
